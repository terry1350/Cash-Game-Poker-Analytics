# Cash Game Poker Analytics

## Project Overview
Analyzed 66,830 No-Limit Texas Hold'em cash game hands
using Python to identify the highest payout earners and
compare their playing characteristics.

## Tools
- Python
- pandas
- Matplotlib
- Jupyter Notebook

## Analysis
- Player hand volume
- Betting and raising frequency
- Total recorded payouts
- Gross payouts per hand
- Top 10 payout earners vs. other players

## Key Findings
- Top 10 payout earners averaged 6,043 hands,
  compared with 1,467 for other qualified players.
- Aggression rates were similar: 23.70% vs. 24.01%.
- Gross payouts per hand were also similar:
  $17.12 vs. $16.66.
- Higher total payouts were strongly associated
  with greater playing volume.

## Limitations
Recorded payouts represent gross winnings, not net
profit. This analysis does not establish which
players were the most profitable.

## Conclusion
The project demonstrates data cleaning, aggregation,
exploratory analysis, and visualization using Python.
