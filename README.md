# Cash Game Poker Analytics

## Project Overview
Analyzed 66,830 No-Limit Texas Hold'em cash-game hands using Python to explore player aggression, hand volume, and recorded gross payouts.

## Tools
- Python
- pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis
- Player hand volume and action-based aggression
- Relationship between aggression and hand volume
- Total recorded gross payouts
- Gross payouts per hand
- Top 10 gross-payout recipients vs. other qualified players (500+ hands)

## Key Findings
- Top 10 payout recipients averaged 6,043 hands versus 1,467 for other qualified players.
- Aggression rates were similar: 23.70% vs. 24.01%.
- Gross payouts per hand were also similar: 17.12 vs. 16.66.
- Higher total payouts were associated with greater playing volume.

## Limitations
Recorded payouts represent gross winnings, not net profit. The aggression metric is action-based rather than a standard poker aggression factor. This analysis cannot establish player profitability.

## Conclusion
Demonstrates data processing, aggregation, exploratory data analysis, and visualization using Python.
